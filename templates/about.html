Method and evidence

Adaptive File Compression System Using Multi-Level Frequency Analysis & Hybrid Huffman

ByteSize is the working interface for the thesis system. It keeps the project’s Hybrid Huffman pipeline intact and verifies every completed compression round trip with SHA-256.

Pipeline

Three decisions, one lossless stream

  1. 01

    Multi-tier frequency scan

    Counts individual bytes and repeated multi-byte structures at several candidate lengths.

  2. 02

    Bit Cost Decision Engine

    Compares the encoded cost of structural blocks against literal-byte coding and keeps only useful candidates.

  3. 03

    Hybrid Huffman encoding

    Builds a canonical Huffman code over the selected structural blocks and remaining literal bytes, then records enough metadata for exact reconstruction.

The two Silesia rows are the same twelve files, measured twice. The originals total 211,938,580 bytes in both, so the comparison is exact: the current engine writes 4,181,865 fewer bytes than the AFC 1.3 audit at the Balanced preset (−4.58%), and 6,810,146 fewer at Maximum (60.13% saved) — smaller on every one of the twelve files, not merely on average. Silesia is regenerated with benchmarks/external_corpus.py, which takes the corpus as a path because it is separately licensed and not redistributed here; the repository-corpus row is regenerated with benchmarks/v9_repo_corpus.py and needs no download. The Canterbury row remains the AFC 1.3 audit over the full eleven-file corpus and is not a claim about the current engine: the official corpus could not be re-measured here, and a partial re-run over only its text files would flatter the result by omitting the binary members that pull the ratio down.

PDF and DOCX need class-qualified interpretation, and GovDocs1 shows why. Across 981 real government documents the result splits sharply by what is already compressed inside the file. Structured and textual formats reduce well — XLS 68.75% over 62 files, CSV 66.00%, TXT 65.57% over 154 files, HTML 64.38% over 181 files, PostScript 62.87% — while formats whose payloads are already entropy-coded barely move: PDF 12.50% over 200 files, PPT 9.21%, SWF 2.99%, GIF 2.88%, JPEG 1.50%, gzip 0.93%. Sixty-one of the 981 files (6.2%) did not shrink at all and were stored verbatim rather than expanded. ByteSize therefore makes no general compression-percentage claim for PDF or DOCX: a PDF of uncompressed text streams behaves like the text it contains, and a PDF of JPEGs behaves like the JPEGs. Every file above — including the ones that did not shrink — was reconstructed byte for byte and SHA-256 verified.
