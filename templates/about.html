Method and evidence

Adaptive File Compression System Using Multi-Level Frequency Analysis & Hybrid Huffman

ByteSize is the working interface for the thesis system. It keeps the project’s Hybrid Huffman pipeline intact and verifies every completed compression round trip with SHA-256.

Pipeline

Three decisions, one lossless stream

  1. 01

    Multi-tier frequency scan

    Counts individual bytes and repeated multi-byte structures at several candidate lengths.

  2. 02

    Bit Cost Decision Engine

    Compares the encoded cost of structural blocks against literal-byte coding and keeps only useful candidates.

  3. 03

    Hybrid Huffman encoding

    Builds a canonical Huffman code over the selected structural blocks and remaining literal bytes, then records enough metadata for exact reconstruction.

PDF and DOCX need class-qualified interpretation. Files with internally uncompressed streams can provide substantial structure for Hybrid Huffman, while ordinary producer-compressed files may offer very little additional reduction. ByteSize therefore makes no general compression-percentage claim for either format; both are reconstructed byte for byte.
